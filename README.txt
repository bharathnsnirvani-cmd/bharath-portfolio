BHARATH NS - STREAMLIT PORTFOLIO

1. Extract this folder.
2. Open the Bharath-Portfolio folder in VS Code.
3. Open the VS Code terminal in this folder.
4. Install dependencies:
      pip install -r requirements.txt
5. Run:
      streamlit run app.py

PROFILE PHOTO:
Your uploaded photo is already included at assets/profile.png.

RESUME:
To enable the resume download button, add your latest PDF as:
      assets/resume.pdf

PROJECT LINKS:
The project cards currently link to your GitHub profile. Replace those with
individual repository URLs once the repositories are public.

CONTACT FORM:
The form validates the fields and prepares an email draft in the visitor's
email application. It does not send email automatically.

DEPLOYMENT:
Push this folder to a GitHub repository, then deploy app.py using
Streamlit Community Cloud at https://share.streamlit.io/
